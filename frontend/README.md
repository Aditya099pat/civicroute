# CivicRoute Frontend

Modern React + Vite frontend for CivicRoute — Municipal Bureaucracy Path Visualizer.

## Features
- **Prerequisite DAG Engine**: Visualizes multi-department municipal clearance lineages.
- **Topological Milestones**: Real-time dependency tracking, document compliance checks, and SLA estimations.
- **Steward & Admin Portal**: Privileged authentication for municipal data stewards and gazette auditors.
- **Compliance Docket Export**: Printable audit summary for physical ward submissions.

## Getting Started

### Install dependencies
```bash
npm install
```

### Run development server
```bash
npm run dev
```

### Build for production
```bash
npm run build
```
